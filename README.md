# Shariful Islam — Premium Portfolio

Static HTML/CSS/JS portfolio designed around a dark editorial creative-developer aesthetic.

## Files
- `index.html`
- `style.css`
- `script.js`
- `robots.txt`
- `sitemap.xml`
- `assets/images/shariful-islam.jpg` — **replace with the user's real portrait**
- `assets/projects/` — optional local project screenshots can be added here later.

## Deployment
Upload the folder to GitHub Pages, Netlify or Vercel.

## Notes
Project descriptions are intentionally conservative where public-site research was incomplete. The project URLs in `script.js` are the supplied portfolio URLs. The visual browser frames are a lightweight replacement system so the site does not depend on random stock imagery; they can be swapped for real screenshots in `script.js` later.
